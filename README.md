Python Lab Assignment – Section C

1. Armstrong Number

Aim: To check whether a number is an Armstrong number and print Armstrong numbers in a given range.

Logic: Calculate the sum of each digit raised to the power of the number of digits. Compare the sum with the original number.

Sample Input: 153

Output: 153 is an Armstrong number.

2. Prime Number

Aim: To check whether a number is prime and print prime numbers in a given range.

Logic: Check whether the number is divisible by any number other than 1 and itself.

Sample Input: 7

Output: 7 is a Prime Number.

3. Perfect Number

Aim: To check whether a number is a perfect number and print perfect numbers up to a given limit.

Logic: Find the sum of all proper divisors of the number. If the sum equals the number, it is perfect.

Sample Input: 6

Output: 6 is a Perfect Number.

4. Palindrome

Aim: To check whether a number and a string are palindrome.

Logic: Reverse the number using arithmetic operations and reverse the string using slicing. Compare both with their original values.

Sample Input: 121 and madam

Output: Both are Palindromes.

5. Fibonacci Series

Aim: To generate Fibonacci series using loop and recursion.

Logic: Each term is the sum of the previous two terms. The program uses both iteration and a recursive function.

Sample Input: 7

Output: 0 1 1 2 3 5 8

6. Pattern Printing

Aim: To print different patterns using nested loops.

Logic: Use nested loops to print a right-angled triangle, number pattern and pyramid pattern.

Sample Input: 5 rows

Output: Three different patterns are displayed.

7. Menu-Driven Application

Aim: To combine multiple Python programs into a single menu-driven application.

Logic: Use a while loop and conditional statements to execute the selected program. The menu repeats until the user selects Exit.

Sample Input: Choice 1, Number 153

Output: Armstrong Number.

8. Number Guessing Game

Aim: To create a number guessing game using random numbers.

Logic: Generate a random number between 1 and 100. Give the user 7 attempts and provide hints if the guess is too high or too low.

Sample Input: A guess between 1 and 100.

Output: Congratulations message if guessed correctly, otherwise the correct number is displayed after 7 attempts.
